# Practice Sorting 01 — "Bubble Sort + Selection Sort"

Implement `BubbleSort(int[] values)` and `SelectionSort(int[] values)` by hand — no `Array.Sort` inside them. Both should sort `values` in place, ascending.

## Self-check
- Works on already-sorted input (shouldn't break, and ideally does less work — bubble sort should be able to stop early once no swaps happen in a pass)
- Works on reverse-sorted input
- Works on input with lots of duplicate values
- Works on an empty array and a single-element array
- Compare your output against `Array.Sort` on the same data to confirm correctness
