# Lab 17 — Exceptions Practice (Ungraded)

This is an **optional, ungraded** practice lab.

## Goal
Practice:
- `try`/`catch`/`finally` control flow
- catching specific exception types rather than a blanket `catch (Exception)`
- defining and throwing your own exception type

Practice prompts:
- `docs/practice/exceptions/practice-exceptions-01.md`

## Run
From repo root:
```bash
make run LAB=src/labs/17-exceptions/CS1302.Lab17.Exceptions
```
