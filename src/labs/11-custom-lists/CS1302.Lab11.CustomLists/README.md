# Lab 11 — Custom Lists Practice (Ungraded)

This is an **optional, ungraded** practice lab.

## Goal

- building a list's internals yourself instead of using `List<T>`
- singly-linked node structures
- implementing `IEnumerable<T>` so `foreach` works on your own type
