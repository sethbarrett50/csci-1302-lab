# Lab 09 — Interfaces Practice (Ungraded)

This is an **optional, ungraded** practice lab.

## Goal
Practice:
- defining and implementing an `interface`
- calling methods through an interface reference, across unrelated classes
- interfaces vs. inheritance: no shared base class is needed
