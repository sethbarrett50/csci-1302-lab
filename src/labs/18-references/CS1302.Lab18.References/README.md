# Lab 18 — References Practice (Ungraded)

This is an **optional, ungraded** practice lab.

## Goal
Practice:
- value types (`int`) passed by value: the callee's changes don't reach the caller
- reference types (a class) passed by reference-to-object: the callee's changes to the object *do* reach the caller
- `out` parameters

Practice prompts:
- `docs/practice/references/practice-references-01.md`

## Run
From repo root:
```bash
make run LAB=src/labs/18-references/CS1302.Lab18.References
```
